# Mrinal Bhoumick - DevOps Engineer Portfolio

A powerful, modern portfolio website with stunning animations showcasing DevOps, cloud infrastructure, and AI engineering expertise.

## Features

- **Powerful Animations**: 3D tilt effects, magnetic buttons, parallax scrolling, and smooth transitions
- **ATS-Optimized Resume**: Professional resume optimized for Applicant Tracking Systems
- **Responsive Design**: Seamless experience across desktop, tablet, and mobile devices
- **Interactive Elements**: Cursor trails, hover effects, floating animations, and scroll-triggered reveals
- **Modern UI**: Gradient effects, glassmorphism, and professional color schemes
- **AWS Certifications**: Showcasing AI Practitioner, Solutions Architect, and Developer certifications
- **Project Showcase**: Detailed IntellIOps platform with measurable business impact metrics
- **Performance Optimized**: Fast loading with smooth 60fps animations

## Quick Start

1. Open `index.html` in your web browser
2. Experience powerful animations as you scroll through sections
3. Navigate using the smart navigation menu (auto-hides on scroll down, shows on scroll up)
4. Click "Download Resume" to get the ATS-optimized version
5. Hover over cards and buttons to see 3D tilt and magnetic effects

## Animation Features

- **3D Tilt Effect**: Cards respond to mouse movement with realistic 3D rotation
- **Magnetic Buttons**: Buttons follow cursor with smooth magnetic attraction
- **Parallax Scrolling**: Multi-layer depth effect on scroll
- **Cursor Trail**: Gradient particle trail following mouse movement
- **Scroll Animations**: Elements fade, slide, and scale into view
- **Timeline Animation**: Experience items slide in from alternating sides
- **Typing Effect**: Hero subtitle types out with blinking cursor
- **Glow Effects**: Pulsing glows on timeline dots and hover states
- **Smooth Transitions**: Cubic-bezier easing for professional feel

## Customization

### Update Contact Information

Edit the following sections in both `index.html` and `resume.html`:

- Email address
- Phone number
- LinkedIn profile URL
- GitHub profile URL

### Add More Projects

In `index.html`, duplicate the `.project-featured` section and update with your project details.

### Modify Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #ff9900;
    /* ... other colors */
}
```

## Downloading Resume

### For Job Applications (Recommended)
1. Click "Download Resume" button on the portfolio
2. Opens `resume-ats-optimized.html` - optimized for Applicant Tracking Systems
3. Click "Download ATS-Optimized Resume as PDF" button
4. Or use Ctrl+P / Cmd+P and save as PDF

### Why ATS-Optimized?
- Simple, clean formatting that ATS systems can parse
- Keyword-rich content matching job descriptions
- Proper heading hierarchy and structure
- No complex styling that confuses automated systems
- Higher chance of passing initial screening
