# Mrinal's Portfolio Website

A modern, interactive portfolio website showcasing cloud & AI engineering expertise, certifications, and projects.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Interactive Animations**: Smooth scroll effects and fade-in animations
- **Downloadable Resume**: Professional resume available in HTML format (can be printed to PDF)
- **Modern UI**: Clean, professional design with gradient effects and smooth transitions
- **Certification Showcase**: Highlights AWS certifications including the new AI Practitioner certification
- **Project Highlights**: Detailed showcase of IntellIOps project with business impact metrics

## Quick Start

1. Open `index.html` in your web browser
2. Navigate through sections using the top navigation menu
3. Click "Download Resume" to view/download your resume

## Files Structure

```
├── index.html          # Main portfolio page
├── resume.html         # Downloadable resume page
├── styles.css          # Main stylesheet
├── script.js           # Interactive features and animations
└── README.md           # This file
```

## Customization

### Update Contact Information

Edit the following sections in both `index.html` and `resume.html`:

- Email address
- Phone number
- LinkedIn profile URL
- GitHub profile URL

### Add More Projects

In `index.html`, duplicate the `.project-featured` section and update with your project details.

### Modify Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #0066cc;
    --secondary-color: #ff9900;
    /* ... other colors */
}
```

## Printing Resume to PDF

1. Open `resume.html` in your browser
2. Click the "Download as PDF" button, or
3. Use browser's print function (Ctrl+P / Cmd+P)
4. Select "Save as PDF" as the destination
